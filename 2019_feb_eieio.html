EIE.io: Smart Farming Using Real-Time Livestock Monitoring

Summary

EIE.io was developed for the AGCO Accelerator 2019 Hackathon, with the goal of helping farmers monitor the well-being of their livestock autonomously. The solution provides real-time alerts for farmers when any livestock shows signs of illness, enabling timely intervention. By leveraging machine learning, we built an end-to-end system that processes images sent from mobile phones or drones, identifies sick animals, and notifies users about where and when to provide assistance.

Explaining EIE.io

Key Contributions

  • Autonomous Livestock Monitoring: Designed an automated pipeline that detects the health status of livestock using images captured by mobile phones or drones, enhancing farm management and animal welfare.
  • Machine Learning Models: Trained two dedicated machine learning models — one for object detection to identify the animal in an image, and another for classifying the animal’s health status as healthy or unhealthy. Separate classifiers were trained for each animal type using a custom dataset.
  • Cloud-Based Architecture: Integrated Google Cloud’s Vision API and Firebase Realtime Database to store and alert farmers about unhealthy animals in real-time without requiring manual refreshes on the application.
  • Web and Mobile App Development: Developed both the mobile and web applications using the React framework, providing a user-friendly interface for farmers to monitor their livestock in real-time.

Key Projects

  • Data Collection and Processing: Collected and labeled images of eight commonly found farm animals (cow, pig, horse, sheep, goat, donkey, rabbit, and chicken) for training the object detection and classification models.
  • Object Detection and Classification: Utilized TensorFlow’s Object Detection API for drawing bounding boxes around animals in images and trained classifier models to detect signs of illness in each animal type.
  • Real-Time Alerts and Visualization: Used Firebase Realtime Database to store unhealthy animal alerts, with real-time updates sent to the web app. Google Maps API was utilized to pinpoint the location of the affected animal on a map, providing visual information to the farmer.

Challenges

One of the main challenges was gathering a large enough dataset of animal images that included various health conditions. We overcame this by focusing on the eight most common farm animals and manually labeling the images for training. Additionally, ensuring real-time updates without compromising performance required the efficient use of cloud services like Firebase and Google Cloud's Vision API.

Technologies Used

  • Languages & Frameworks: HTML, Javascript, Python, React, Flask
  • Machine Learning: TensorFlow, Google Cloud’s Vision API, GCP ML Engine
  • Cloud Services: Firebase Realtime Database, Google Maps API
