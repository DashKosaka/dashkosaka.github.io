Getting Started with ROS: A Journey into Robotics Middleware

Robot Operating System (ROS) is a tool widely used for data visualization and processing in robotics and beyond. Surprisingly, despite its name, ROS isn’t an operating system but a flexible middleware that connects various robotic components. Here, I'll break down its architecture and what makes it such a versatile platform.

ROS Architecture: A Simple Breakdown

At a high level, a ROS stack revolves around three key components:

1. Launch Files

Launch files sit at the top level and define the parameters for an application, including any relevant ROS nodes needed for it. These files serve as the main entry point, initiating various processes in a controlled manner.

2. ROS Nodes

ROS nodes are fundamental to ROS. Each node is an application that can receive inputs, process them, and publish outputs. The term publish is central here—once data is published by a node, it’s available on the ROS server. This setup is powerful because any other node in the network can subscribe to published data, creating a modular system that’s easy to expand and adapt. With nodes designed to work with each other’s outputs, it’s possible to build complex, interdependent systems in a straightforward way.

3. ROS Messages

ROS messages define the data types passed between nodes. These messages can represent almost anything necessary for robotic applications—arrays, point clouds, images, and more. And if a custom data structure is needed, ROS allows creating it as long as it can be formatted like a struct. ROS messages come with useful features like timestamps and unique hashes to maintain data versioning and ensure consistency across nodes.

The Power of Modularity

With these three components, ROS builds a modular system with clear data definitions. New nodes can be added as needed, and the structure remains highly adaptable. Data is stored in a format called ROSbag, a chronologically ordered container that saves all published messages along with their timestamps. This feature means that an entire session’s data capture can be reproduced exactly, which is crucial for testing and benchmarking algorithms in realistic settings.

One standout feature is the playback capability, allowing ROSbag data to be transmitted as though it’s being captured live. This lets us rigorously test and evaluate new algorithms by replaying real-world data captures.

Using ROS in Practice

Many of these features play a central role in my current work at Uhnder, where I use ROS to prototype algorithms like occupancy grid maps, trackers, and alignment algorithms. I often start with a lightweight setup in Python, which makes rapid development and adjustments easy. Frequently, I rely on real-world data captured in ROSbags to validate my models and test their effectiveness.

When developing these algorithms, I also create custom messages tailored to the specific outputs I need to analyze. For instance, I’ve built messages that support point clouds with additional fields and 2D maps, allowing for more detailed insights into the data. Transitioning from prototype to proof of concept is straightforward thanks to ROS's visualization tools, which enable a clear, comprehensive view of how the data behaves.

Benefits of a Bilingual Development Environment

ROS’s flexibility extends to its support for both C++ and Python for node development. This allows me to quickly build lightweight prototypes in Python that can run independently or integrate seamlessly with the rest of the ROS stack. When speed and performance are critical, transitioning a node to C++ is straightforward, giving ROS the flexibility of fast-paced prototyping with the robustness of C++ for production-ready applications.

Conclusion

Learning ROS has been a deep dive into building and connecting modular components. With its simple yet powerful architecture and robust data handling, ROS has become an essential tool in my robotics toolkit. From enabling cross-node communication to offering reliable data playback for testing, ROS has the versatility that makes it invaluable in robotics and autonomous systems.
