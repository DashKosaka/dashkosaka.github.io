TyperML: An AI-Powered Typing Improvement Tool

Summary

In December 2018, I developed TyperML, an exploratory project aimed at improving users' typing speed and accuracy. Inspired by the popular typing game TypeRacer, TyperML uses machine learning concepts to create a personalized, interactive typing experience that adapts to each user's unique mistakes and habits.

Key Contributions

  • Designed a gamified system to help users improve their typing ability through customized challenges.
  • Created an interactive GUI in Pygame that gradually learned from users’ typing patterns and errors.
  • Combined Recurrent Neural Networks (RNNs) and Generative Adversarial Networks (GANs) to generate novel and progressively challenging typing exercises tailored to each user.
  • Developed separate neural networks to predict keystroke accuracy and speed, providing real-time feedback to improve typing skills.

Challenges

The primary challenge of TyperML was combining two different neural network models (RNNs and GANs) in a meaningful way that would both learn from and challenge the user. Balancing the difficulty curve to adapt to users without overwhelming them also required careful fine-tuning of the models. Additionally, generating random but coherent sentences using Markov Chains added another layer of complexity to the project.

Technologies Used

Python, Recurrent Neural Networks (RNNs), Generative Adversarial Networks (GANs), Markov Chains, Pygame
