Deep Fake Farms: Farming the Future With Deep Fake Technology

Summary

Deep Fake Farms was a project developed for the AGCO Accelerator 2019 Hackathon, with the goal of utilizing deep fake technology to generate vast amounts of unique, prelabeled image data for agricultural datasets. Inspired by techniques typically used to mimic human faces, this data augmentation approach helped create synthetic agricultural imagery, offering a scalable solution for training machine learning models in agricultural contexts.

Explaining Deep Fake Farms

Key Contributions

  • Data Augmentation for Agriculture: Designed a novel data augmentation technique that could generate significant volumes of synthetic image data for agricultural land. This was particularly useful for training models on scarce datasets of satellite imagery.
  • Manual Data Curation: Procured a dataset of satellite images and manually labeled and preprocessed the data using OpenCV. This provided a high-quality training set for the generator/discriminator model.
  • Generative Framework: Developed a generator/discriminator-based generative adversarial network (GAN) in Pytorch, where a DeCNN was responsible for generating unique agricultural images, and a CNN discriminator inferred which pixels belonged to real farmland on a per-pixel basis.
  • Distributed Data Generation: Implemented a distributed technique for generating smaller samples of augmented data that could later be merged into larger outputs, providing flexibility in generating images of varying sizes.
  • Transfer Learning for Rapid Prototyping: Leveraged transfer learning to produce reasonable outputs in less than 24 hours, accelerating the development cycle within the tight time constraints of the hackathon.

Key Projects

  • Data Preprocessing: Used OpenCV for image preprocessing and manual labeling, ensuring that the input data was of high quality for training the GAN framework.
  • GAN Framework: The GAN consisted of a DeCNN for data generation and a CNN for discrimination, with per-pixel accuracy. This framework could generate synthetic agricultural images with corresponding segmentation labels.

Challenges

One of the primary challenges was generating high-quality data within the tight 24-hour timeframe of the hackathon. This required careful balancing between image resolution, output quality, and the computational constraints. Transfer learning and distributed data generation techniques were critical to achieving the necessary results within the limited time.

Technologies Used

  • Languages & Libraries: Python, OpenCV, Pytorch
  • Machine Learning Techniques: Convolutional Neural Networks (CNN), Deconvolutional Neural Networks (DeCNN), Generative Adversarial Networks (GAN)
  • Tools: Jupyter Notebook
  • Specializations: Remote Sensing, Data Augmentation
