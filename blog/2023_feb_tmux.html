Boosting Productivity: tmux

When it comes to productivity on a Linux machine, few tools have made as big of an impact on my workflow as tmux. It's a versatile terminal multiplexer that I rely on almost every day. In this post, I want to share three key ways that tmux has transformed how I work: running long and overnight scripts, managing complex tasks across multiple terminals, and keeping my daily work organized.

Running Long Scripts with Ease

One of the most common use cases for tmux is running long or indefinite scripts—especially when working remotely. If you've ever ssh'ed into a remote machine and needed to execute a process that takes hours or days to complete, you'll know the challenge: staying connected without interruption. Early on, I faced this issue often, where jobs would terminate if my connection dropped.

With tmux, however, that problem is solved with a single command. Once you start a tmux session, you can run your script, safely disconnect from the machine, and check back in whenever you need. The server persists even after your terminal closes. I've relied on this countless times, particularly when running tests that capture data over days. It’s impossible to stay connected that long, but tmux ensures that my work continues in the background.

Some helpful commands:

  • tmux new - Creating a session via tmux server
  • tmux detach or ctrl-b + d - Exit the session while keeping the server running
  • tmux attach - Re-enter the session that was previously created
  • tmux kill-session or tmux kill-server - Kill the tmux session or server

    • Maintaining Workflow Across Sessions

    As my usage evolved, tmux became more than just a tool for running scripts. It became central to my daily development process. At work, I regularly ssh into Linux machines, and before tmux, I used to take meticulous notes to remember my place when closing my laptop. But with tmux, I no longer need to worry about that.

    Now, every time I ssh into a machine, I immediately re-enter the tmux session I was working on before. My directories, command history, and environment remain intact. Often, I’ll leave my tmux server running for weeks at a time, allowing me to pick up right where I left off without missing a beat. If I need to work on a side project or run another task, I simply open a new window within the session—no fuss, no need to reorganize.

    Some helpful commands:

  • ctrl-b + : - Enter in a tmux specific command
  • tmux new-window - Create a new window within the session
  • tmux rename-window or tmux rename-session - Rename the current window or session
  • ctrl-b + w - Navigate created sessions and windows
  • ctrl-b + [ - Navigate through output history

    • Handling Complex, Multi-Machine Setups

    Finally, tmux shines when dealing with more specialized tasks. A particularly useful case I encountered was when using a radar connected to two different machines. I needed to control both machines simultaneously from one terminal. tmux allowed me to ssh into both systems at once and manage communication between them effortlessly.

    Beyond that, tmux’s built-in functionality to synchronize panes, block windows to ensure task execution order, and programmatically manage sessions offers complete control over any complex setup. Whether it’s chaining commands or managing dependencies across machines, tmux makes it all manageable and efficient.

    Some helpful commands:

  • tmux send-keys -t session:window - Send keys or commands to a given window within a session
  • tmux wait-for and tmux wait-for -S - Block and unblock a window from executing any more code until a signal is sent

    • Conclusion

    Tmux isn’t just a tool—it’s become an essential part of my workflow. Whether I'm running overnight scripts, maintaining weeks of work across machines, or orchestrating complex tasks involving multiple terminals, tmux keeps me productive. If you haven’t yet explored its full potential, I highly recommend giving it a try. You might be surprised at just how much it can simplify your development process.
